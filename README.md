# 💻 Desafios Tech Sisters

Este repositório reúne as minhas soluções para os desafios de programação propostos pela comunidade **Tech Sisters**.

O objetivo é praticar programação, desenvolver o raciocínio lógico e acompanhar a minha evolução através da resolução de desafios.

## 🚀 Desafios

| Desafio | Tema | Linguagem |
|---|---|---|
| #01 | Primeiro desafio | Python |
| #02 | Informações do Usuário | Python |
| #03 | Meta de Passos | Python |

## 🛠️ Tecnologias e ferramentas

- Python
- VS Code
- Git e GitHub
- Draw.io — criação de fluxogramas

## 📚 Metodologia de aprendizagem

Para cada desafio, procuro:

1. Analisar o problema e identificar os requisitos.
2. Desenvolver um fluxograma para representar a lógica.
3. Implementar a solução em Python.
4. Testar o programa com diferentes entradas.
5. Registar a solução e a aprendizagem no GitHub.

## 🎯 Objetivo

Consolidar os fundamentos de programação, melhorar a capacidade de resolução de problemas e construir um histórico de aprendizagem contínua.
